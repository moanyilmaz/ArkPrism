\section{Conclusion}
\label{sec:conclusion}

We presented \mytool, a static analysis framework that addresses the source identity resolution bottleneck in \arkts privacy analysis. While HapFlow solves taint propagation, \mytool solves the preceding problem: reliably identifying which API calls are privacy-sensitive, resolving their identities across package migration and receiver factories, and binding them to asynchronous consumers. The core contributions are package- and receiver-aware API identity resolution $\mathit{Id}(v)$, asynchronous source binding $\mathit{SrcBind}(call, callback, param)$, and provenance-annotated evidence subgraphs. On the ArkPrismBench stratified benchmark (164 projects), \mytool achieves 100\%/100\% precision/recall; HapFlow's method-signature matching detects at most 68.7\% of gold usages. Callback analysis is the dominant component, improving taint flow recall from 51.5\% to 97.8\% ($p<0.001$). The full pipeline analyzes 1,015 projects in $\approx$4.2\,h wall time with 99.8\% completion, providing scalable privacy audit evidence with full provenance transparency.
