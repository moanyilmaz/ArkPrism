## Release Gate

The paper-facing corpus result is releasable only when all of the following hold:

1. one final-build run contains exactly the 1,014 retained projects;
2. all retained projects complete strict SDK loading, PTA, and one unbatched IFDS execution;
3. no retained report records timeout, budget exhaustion, or fallback;
4. every taint path has resolvable endpoints, a valid provenance label, and source kind `privacy_data` or `framework_input`;
5. every detector-to-flow link has valid indices, compatible source evidence, and a `privacy_data` endpoint;
6. tables, figures, and prose are regenerated from that run and its manifest.
